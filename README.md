# 自动记账应用

一个支持多货币的智能记账应用，特别针对iOS用户优化，支持Apple Pay和银行卡交易自动记录。

## 功能特性

### 💰 多货币支持
- 支持 EUR（欧元）、CHF（瑞士法郎）、USD（美元）、CNY（人民币）
- 自动显示原始金额和EUR等值
- 实时汇率换算（需要配置实际汇率源）

### 📱 iOS 深度集成
- **PWA支持**: 可以安装到主屏幕，像原生应用一样使用
- **快捷指令**: 通过Siri语音快速记账
- **Apple Pay集成**: 自动识别Apple Pay交易（需要配置）
- **通知支持**: 及时提醒和反馈

### 🏦 银行集成
- **短信解析**: 自动解析银行交易短信
- **LCL银行支持**: 专门支持LCL银行卡交易格式
- **多种货币识别**: 自动识别短信中的货币类型

### 📊 智能分类
- **自动分类**: 根据商户名称智能分类
- **可自定义**: 支持添加自定义分类规则
- **多种类型**: 餐饮、交通、娱乐、日用品等

## 如何在手机上使用

### 方法1: 直接访问网页版
1. 在手机浏览器中打开应用地址
2. 书签收藏以便快速访问

### 方法2: 安装PWA（推荐）
1. **iPhone/iPad用户**:
   - 在Safari中打开应用
   - 点击底部分享按钮 📤
   - 选择"添加到主屏幕"
   - 点击"添加"完成安装

2. **Android用户**:
   - 在Chrome中打开应用
   - 点击菜单按钮（三个点）
   - 选择"安装应用"或"添加到主屏幕"

### 方法3: iOS快捷指令集成
1. 打开iOS"快捷指令"应用
2. 点击应用中的"安装快捷指令"按钮
3. 配置以下快捷指令：
   - **快速记账**: 语音输入金额和类别
   - **Siri记账**: "Hey Siri，记账"
   - **扫描短信**: 自动解析银行短信

## 使用说明

### 手动记账
1. 点击"记支出"或"记收入"按钮
2. 输入金额、选择分类、添加描述
3. 确认日期后保存

### 短信自动记账
1. 点击"扫描短信"按钮
2. 粘贴银行短信内容，例如：
   ```
   LCL: 您的卡尾号1234于12月15日在CARREFOUR消费CHF 45.60
   ```
3. 系统自动解析并创建记录

### Apple Pay 集成（需要开发者配置）
- 系统可以自动识别Apple Pay交易
- 根据商户名称自动分类
- 支持多种货币的交易记录

## 数据管理

### 查看统计
- **今日统计**: 显示当天收入、支出、结余
- **交易历史**: 按时间顺序查看所有交易
- **分类统计**: 按类别查看支出分布

### 货币显示
- 原始交易货币金额
- EUR等值金额（用于统计）
- 例如：`CHF 45.60 (€43.22)`

## 开发和部署

### 本地运行
```bash
cd auto-accounting-app
npm install
npm start
```

### 生产部署
```bash
npm run build
npm start
```

应用将运行在 `http://localhost:3000`

## 注意事项

### 关于银行集成
- 目前仅支持短信手动粘贴解析
- **不需要**获取LCL应用的访问权限
- **不需要**连接银行API
- 完全基于用户手动输入的短信内容

### 关于Apple Pay
- 需要开发者账号配置
- 需要商户标识符
- 仅在真实设备上测试有效

### 关于汇率
- 当前使用示例汇率
- 建议连接实时汇率API
- 或手动更新汇率配置

## 隐私和安全

- ✅ 数据完全本地存储
- ✅ 不上传个人银行信息  
- ✅ 不需要银行账号密码
- ✅ 不需要访问银行应用
- ✅ 支持数据导出和备份
